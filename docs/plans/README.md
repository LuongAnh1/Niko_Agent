# Kế Hoạch Triển Khai

Folder này chứa các kế hoạch ngắn hạn hoặc kế hoạch liên quan trực tiếp đến
triển khai. Quy ước:

- Tên file bắt đầu bằng ngày `YYYY-MM-DD`.
- Header trong file ghi ngày lập/cập nhật.
- Nội dung phải chốt rõ phạm vi, giả định, các phase và test cần có.

Roadmap dài hạn không đặt ở đây; dùng `docs/memory/` hoặc folder domain tương
ứng.
